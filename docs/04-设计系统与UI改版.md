# 设计系统与 UI 改版方案

> 产出日期:2026-08-18
> 地位:UI 改版的施工依据。参考调研截图存 `design-refs/`(本地,已 gitignore 候选)
> 原则:参考结构,不抄内容;字体只用免费且支持西里尔字母的

## 0. 设计方向(用户拍板)

**"极简画廊 + 一个互动招牌"**:大量留白、细字重超大标题、单一彩色点缀、克制的慢动效;招牌交互 = 可交互中国地图。

反面清单(明确不做):emoji 当图标(换 lucide)、横向长卷页(移动端/SEO 代价大)、重型 3D(远期可选)、花哨多色。

## 1. 参考站调研结论(2026-08-18,4 站实测拆解)

| 参考站 | 借鉴点 |
|---|---|
| fundaacps.org(教育基金会) | 编号+发丝线目录列表;pill 按钮两段式弹跳 hover;深藏青+柠檬黄+主红的配色示范 |
| findrealestate.com(房产) | 图片 5 秒缓缩放入场("不慌不忙"的来源);米白底+灰蓝点缀+直角细框按钮;横向画廊首页结构 |
| realestateabbey.com/find(房产) | 详情页"聚焦画廊"布局(主图轮播+缩略图栏+参数手风琴+CLOSE);散落画廊卡片 |
| travel-sensations.com(旅游,Awwwards 提名) | 地图点国家→flyTo+填色+底部抽屉卡片;Mega Menu 层级(洲→国);详情 hero 经线 SVG+坐标小字 |

⚠️ 安全:fundaacps.org 与 travel-sensations.com 间歇性被恶意跳转劫持,**勿在浏览器直接打开**;调研已通过请求拦截完成,截图存档。

**共识配方(四站一致)**:暖米白底 + 近黑文字 + 单一红系点缀 + 1px 发丝线 + 无阴影 + 慢动效(高级感=慢+克制)。

## 2. 设计 Token(施工值)

- **色**:背景 `#F7F6F5`(暖米白)/ 文字 `#141414` / 点缀红 `#D91F1F` / 辅助灰蓝 `#6C7E85` / 发丝线 `rgba(0,0,0,.1)`
- **字体**(全部免费 + 原生西里尔):
  - 无衬线正文/UI:**Onest**(或 Manrope)
  - 衬线标题/强调词:**Playfair Display**(或 IBM Plex Serif)
  - 大字标:Onest Light 300 全大写(细字重路线)
- **圆角**:按钮胶囊(pill);卡片/图片 0-8px;**禁用阴影堆叠**,用留白和发丝线分层
- **图标**:lucide-react(替换全部 emoji)

## 3. 动效清单(轻量实现)

| 效果 | 实现 | 用在哪 |
|---|---|---|
| 图片 5s 缓缩放入场 | IntersectionObserver + CSS transition | 列表卡片、详情头图 |
| 标题逐词/逐字母浮现 | Framer Motion split text | 首页大标语、详情页标题 |
| 按钮两段式弹跳 hover | CSS transition + delay | 全站 CTA |
| 卡片 hover 微放大 | Tailwind group-hover | 学校/奖学金卡片 |
| 滚动渐现 | IntersectionObserver | 各页区块 |
| 平滑滚动 | Lenis | 全站 |
| 页面过渡 | CSS View Transitions(不用 Swup,和 App Router 有摩擦) | 全站 |

## 4. 页面方案

- **首页**:超大俄语标语(逐词浮现)→ 编辑感数据区(大数字:学校数/项目数/实时汇率)→ **互动中国地图**(MapLibre 免费;点省份→flyTo+填红→底部抽屉出该省学校小卡+「查看全部」)→ 奖学金入口
- **学校列表页**:编号+发丝线目录式列表;筛选器层级化(地区→城市,参考 Mega Menu)
- **学校详情页**:聚焦画廊(主图轮播 Swiper+缩略图栏+参数手风琴+返回);hero 可叠加经线 SVG+坐标小字细节
- **项目详情页**:同详情页体系,费用卡保持双币种(实时汇率)
- **奖学金目录**:目录式列表;截止时间筛选参考月份 tab 的红斜体衬线选中态

## 5. 施工顺序(每步用户浏览器验收)

1. 设计 token + 字体接入 + 全局壳(导航/页脚)
2. 首页(大标语+数据区+动效;地图作为独立步骤压轴)
3. 学校列表页
4. 学校详情页
5. 项目详情页 + 奖学金目录
6. 互动地图(MapLibre,含省份抽屉)
7. 精修:微交互、暗色模式适配评估、移动端

## 6. 技术栈新增依赖(届时按需安装)

framer-motion、lenis、maplibre-gl、swiper、lucide-react
