# 竞品调研与业务逻辑洞察

> 调研日期：2026-07-28
> 目的：在确定数据模型和业务逻辑之前，记录同类平台/开源项目的模块划分、业务流程与变现模式，作为后续设计决策的依据。
> 状态：初步调研，部分信息为平台自述口径（文中已标注），未独立验证。

---

## 1. 核心结论(TL;DR)

1. **"项目(Program)"是行业的核心实体，不是大学。** 所有成熟平台都以项目卡片为最小信息单元。
2. **奖学金(Scholarship)在俄语市场是一等公民**，必须单独建模，不能只是项目的一个字段。
3. **俄语市场没有真正的"信息平台"**——现有玩家要么是英文平台(无俄语化)，要么是中介落地页(信息不透明、只有合作院校)。无渠道偏见的全量数据库是空白。
4. **开源世界没有可直接 fork 的 starter**，自建 Next.js + Prisma + Better Auth 骨架是现实路径；信息架构和申请管线模型有现成参考。
5. 申请漏斗是行业通用状态机：选项目 → 交材料 → 付申请费 → 录取通知(Admission Notice) → JW202/签证 → 行前。

## 2. 商业平台的模块拆解

### 2.1 CUCAS — [cucas.cn](https://www.cucas.cn)

老牌"中国大学招生系统"(2008 年前后)，技术栈 PHP + nginx。

**模块清单:**

| 模块 | 说明 |
|---|---|
| 项目目录/搜索 | 首页即项目卡片流；筛选:学位、学科、城市、授课语言、学费 |
| 项目详情页 | 标准化字段:Degree、Starting Date、Duration、Teaching Language、Tuition Fees、Application Deadline、Application Fee、Service Fee |
| 大学子站 | 每所大学一个子域名(如 uibe.cucas.cn):学校简介、"Why choose"证言、University Comparison 对比工具、Useful Documents、学生 Reviews |
| 申请系统 | 6 步漏斗:Choose a Course → Apply → Get Accepted → Apply for Visa → Pre-departure → Start Studying |
| 用户账户 | 申请状态跟踪 |
| 裂变营销 | 邀请好友返 1000 RMB |

**商业模式:** 免费信息 + 申请费代收(USD 29–135)+ 服务费(约 USD 100/项目)+ 奖学金服务费(USD 200)+ 大学渠道佣金(自述 30%–50% 学费减免，未验证)。

### 2.2 China Admissions — [china-admissions.com](https://www.china-admissions.com)

2010 年成立，营销站 WordPress + 申请站 Python Django(已验证响应头)。

**模块清单:**

| 模块 | 说明 |
|---|---|
| 营销/内容站 | Blog、Testimonials、分类专题(MBBS/MBA/Chinese Language/Scholarships/PhD/Online) |
| SEO 专题页矩阵 | "学科×学位×国家"落地页(如 /topic/Bachelors-in-Artificial-Intelligence-in-China/)——主要获客引擎 |
| 搜索应用 | apply.china-admissions.com:Bachelor 2530 / Master 4927 / PhD 2992 / Non-degree 242；筛选:城市、项目、入学批次(intake)、学费区间 |
| 项目详情页 | 大学图文介绍(Features bullet)+ 时长/语言 + due dates + eligibility requirements |
| 申请系统 | 8 步漏斗，"填表传材料约 12 分钟"；状态更新邮件通知 |
| 人工顾问 | 每名学生分配专属 admission officer——服务核心卖点 |
| 增值服务 | 付费 admissions review、MBBS 保证录取套餐、电话咨询预约 |

**商业模式:** 基础申请免费 → 增值服务收费 + 大学渠道佣金。

### 2.3 官方 CSC 系统 — [campuschina.org](https://www.campuschina.org)

- 中国政府奖学金唯一官方入口；申请系统 studyinchina.csc.edu.cn。
- 结构:按省份浏览大学 → 查招生专业；Type A/B 项目 + Agency Number(受理机构编号)制度。
- **体验极差**:仅中英双语、官方建议 Firefox/IE11、流程抽象。
- **启示:把 CSC 申请流程翻译成 step-by-step 俄语向导，本身就是高价值内容产品。**

### 2.4 俄语市场玩家

| 平台 | 形态 | 技术栈 | 特点 |
|---|---|---|---|
| [Red Planet China](https://redplanetchina.com/catalog/china/) | 目录型中介 | Nuxt/Vue 自研 | 唯一像"产品"的竞品:266 所院校、多维筛选(城市/类型/18 种项目层级/授课语言/616+ 专业/奖学金)、卢布标价、截止日期。**但只覆盖合作院校，有渠道偏见** |
| [PortalChina](https://www.portalchina.ru/) | 中介落地页 | WordPress | 老牌(2009 起),10 步服务流程图、合同模板可下载——信任建设标配 |
| [StudyChina](https://studychina.ru/) | 中介落地页 | WordPress | 无公开院校目录，信息由顾问掌握 |
| [ChinaCampus.ru](https://chinacampus.ru/) | 官方联盟代表处 | WordPress | CCN 37 所大学 logo 墙，无结构化目录 |
| VK/Telegram 社群 | 社群 | — | 俄语申请者获取 CSC 信息、互助的主要渠道 |

**俄语中介套餐价格带(参考):** 申请套餐 3–16 万卢布；签证代办 27,000 ₽；接机安顿 35,000–45,000 ₽；付款惯例 50% 签约 + 50% 录取后。

**俄语市场特有观察:**
- "грант"(奖学金)几乎在所有俄语站首屏——奖学金信息是刚需。
- 决策链里有父母，文案常对家长说话。
- 俄罗斯用户无法用 Visa/Mastercard 国际通道付人民币——后期接申请时支付通道(МИР/СБП/代理支付)是特有产品问题。
- 项目层级比英语市场更细:语言班/预科/1+4/2+2/双文凭/专升本——大量学生走"语言年→本科"路径。

## 3. 开源项目调研

**总体结论:该领域没有成熟开源 starter。** 高 star 项目都是内容型知识库；软件平台几乎都是 0–10 star 练手项目，且全部**没有开源许可证**(只能参考思路，不能复制代码)。

### 3.1 值得参考思路的两个项目

**admission-atlas** — [github.com/nevskiyinnity/admission-atlas](https://github.com/nevskiyinnity/admission-atlas)(0 star,2026-04 更新，无 License)
- 栈:Next.js 14 (App Router) + TypeScript + PostgreSQL + Prisma + Clerk + next-intl 双语 + Tailwind/Radix——**与我们计划的栈几乎同构**(认证换 Better Auth 即可)。
- 架构参考:`[locale]` i18n 路由 + 按角色分组的 dashboard + middleware 角色守卫 + Prisma singleton。
- **申请管线数据模型(后期直接借鉴):** Project(每个申请)→ Milestone → Task → Message → File,外加 Notification 和 AuditLog。
- 三角色:Admin / Counselor / Student。

**OpenCSApp** — [opencs.app](https://opencs.app) / [github.com/opencsapp](https://github.com/opencsapp/opencsapp.github.io)(2.3k star，领域唯一有社区规模)
- 信息架构三件套:**项目库 + 众包 DataPoints + FAQ**。
- DataPoints 模式:用户提交自己的背景(GPA/语言/科研)和录取结果，换取查看他人数据的权利——**解决信息平台冷启动的最佳已知模式**，用户数据滚雪球。

### 3.2 其他(仅备查)

- [pandaoffer-web](https://github.com/silverlion2/pandaoffer-web):来华留学营销站(2 star),可参考服务页转化路径。
- [gaokao](https://github.com/charlieJ107/gaokao)(8 star，已废弃):高考志愿查询系统，"免费透明数据 vs 中介信息垄断"的定位叙事与我们同构。
- 知识库类(内容组织可参考):[Women-Study-Abroad](https://github.com/Celiashea/Women-Study-Abroad)(409 star)、[career-plan](https://github.com/nwuzmedoutlook/career-plan)(278 star)。

## 4. 提炼:行业通用的业务逻辑

### 4.1 信息架构(所有平台收敛后的最小集)

```
University(大学)
 ├── 名称(中俄英)、城市/省份、类型、排名标签(985/211/双一流)
 ├── 简介、官网、住宿信息、校园图片
 └── Program[](项目)
      ├── 学位层级:语言班/预科/本科/硕士/博士/短期(俄语市场需细分 1+4、2+2、双文凭)
      ├── 学科专业、授课语言(中/英/俄)
      ├── 学制、开学日期、申请截止日期、入学批次(intake)
      ├── 学费(人民币/年;俄语市场需卢布换算展示)
      ├── 申请费、申请资格、所需材料清单
      └── Scholarship[](奖学金):类型(CSC/省政府/校内)、覆盖范围、截止日期、申请通道

Post/News(动态资讯)——可挂在大学下或平台级
FAQ + 指南内容(签证、CSC 流程、行前)——获客与 SEO 引擎
```

### 4.2 申请漏斗(后期功能的行业通用状态机)

```
选项目 → 提交材料 → 支付申请费 → 审核/提交学校 → 状态跟踪
  → 录取通知(Admission Notice) → JW202 表 → 签证(X1/X2) → 行前准备 → 入学
```

- 两个关键里程碑文档:Admission Notice、JW202——状态设计围绕它们。
- 参考 admission-atlas 的实现模型:Application(Project)→ Milestone → Task → File/Message + Notification + AuditLog。

### 4.3 转化漏斗(获客→变现)

```
免费内容(SEO 专题页/博客攻略/费用计算器/Telegram 频道)
  → 留资(注册/订阅/下载模板)
  → 自助信息服务(收藏、对比、申请进度)
  → 付费服务(申请代办/材料审核/签证/接机)/ 大学渠道佣金
```

### 4.4 变现模式清单(已被市场验证,后期可选)

1. 申请费代收 + 服务费(CUCAS:USD 100–200/项目)
2. 付费申请审核/保证录取套餐(China Admissions MBBS 服务)
3. 大学渠道佣金(Sinosphere 模式——对用户免费)
4. 增值服务逐项收费:签证、接机、找房、HSK 课程(俄语中介 5,000–185,600 ₽ 不等)
5. 分期付款惯例:50% 签约 + 50% 录取后

## 5. 我们的机会点(差异化)

1. **无渠道偏见的全量数据库**:覆盖所有中国大学+项目，中立标注"可自助申请 / 需中介",而非只推合作院校。
2. **俄语原生 + 双币种**:界面俄语优先，学费人民币/卢布双币种展示(汇率换算)。
3. **结构化奖学金数据库**:CSC Type A/B、省级、校内奖学金的类型/覆盖/截止日/通道/材料——目前俄语用户靠 Telegram 群拼凑。
4. **CSC 流程的俄语 step-by-step 向导**(官方系统体验极差，解释型内容有真实价值)。
5. **价格与决策透明**:公开"DIY vs 找中介"决策工具、费用计算器(城市/大学/项目/语言/住宿五维——Sinosphere 验证过的钩子)。
6. **DataPoints 式冷启动**(借鉴 OpenCSApp):用户提交背景+录取结果换取查看他人数据。
7. **申请进度时间线**:中介模式下学生看不到进度,账户+状态时间线即使先做展示也有价值。

## 6. 对我们数据模型/架构的初步影响(待晚上讨论确认)

- 以 `University → Program` 两级为核心,`Scholarship` 独立建表。
- 角色字段第一天就要留:student / university_admin / platform_admin(后期 counselor)。
- i18n 第一天进架构:`[locale]` 路由 + 内容表多语言字段(可先只做中文维护 + 俄文展示)。
- MVP 先做信息平台，避开与中介正面竞争;申请功能的状态机/模型已有模板可循，不必现在建。
- 模块化单体:auth / universities / programs / scholarships / news / users 各自独立 service 层。

## 9. 讨论纪要(2026-07-28,调研后对齐)

### 9.1 已确认的决策

1. **覆盖范围**:全部招收国际学生的中国高校(约 800–1000 所)。授课语言是 Program 的字段,不是平台边界——中文/英文/俄语授课项目都覆盖(俄语授课极少,但有,是差异化内容)。
2. **数据更新策略**:不做"实时监控",按数据分三层——
   - 静态层(学校简介/位置/排名):人工录入,偶尔校对
   - 周期层(项目/学费/学制):年度更新,招生季前集中刷新
   - 时效层(截止日期/奖学金窗口/动态):变更检测监控
3. **数据获取路径(分阶段)**:
   - MVP:人工 + LLM 辅助录入,精修 Top 100–200 所(爬虫是录入助手,不是产品;CMS 和数据质量才是)
   - 二期:定向爬虫管道(通用爬取 + LLM 结构化抽取 + 内容 hash 比对),按学校优先级排定时任务
   - 三期:变更检测(可参考开源 changedetection.io),变更后"重新抽取 → diff → 人工确认 → 入库";人工确认环节不可省
   - 长期:学校官方入驻自助维护(CUCAS 子站模式)——schema 需预留 university_admin 角色
4. **结构复用原则**:信息架构/字段/漏斗照搬成熟平台;**内容文案不可照抄**(版权 + SEO 重复内容降权),数据从学校官网等源头自行组织。
5. **变现模式**:freemium——信息全量免费(流量引擎/SEO 资产);付费的是"省时间和确定性"(录取数据、截止提醒、对比工具、进度跟踪);服务层(申请代办/材料审核/签证)为主要收入来源。冷启动阶段不对信息收费(竞品信息全免费,收费会掐死网络效应飞轮)。
6. **多语言内容生产**:俄语界面与内容翻译可由 LLM 初译,俄方合伙人复核地道性即可,不必由他手工翻译。

### 9.2 分工:俄罗斯合伙人在信息平台阶段的任务

1. **俄语搜索行为调研**:摸清俄罗斯学生在考虑来华留学时实际搜索什么词汇(Yandex/VK/Google 俄语关键词)——直接决定我们的 SEO 落地页矩阵和内容选题。
2. **俄罗斯支付通道调研**(重点):摸清俄罗斯用户可行的付款方式(МИР/СБП/代理支付/加密货币等)——这是后期接申请收费、服务变现前必须解决的前提。
